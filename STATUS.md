# GymLeader Project Status

![Status: Active](https://img.shields.io/badge/status-active-success.svg) ![Version 1.0.0](https://img.shields.io/badge/version-1.0.0-blue.svg)

This document provides an overview of the current status, future roadmap, and known issues for the GymLeader project. It is updated regularly to keep the community and collaborators informed.

---

## 🎯 Current Status

**Stable Version:** 1.0.0

### Recent Achievements
- 🎉 **Version 1.0.0 Launch:** The first public version of GymLeader is now available, enabling the users to import pokemon cards, create their gym and battle.

### 🔬 Team Focus
- **Feedback Collection:** Actively analyzing community feedback to prioritize upcoming improvements and features.

## 🐞 Known Issues

Below is a transparent list of issues we have identified and are on our radar to fix.

- **First Access Clarity:** Currently, the user is not being guided correctly to access their wallet and import cards before creating a gym and battle.


## 🗺️ Roadmap

Our roadmap is guided by community needs and our vision to make creating AI solutions more accessible.

### Version 1.0.1 (Next Release)
- [ ] **First Access Clarity:** Use empty collect field to redeeem cards.
- [ ] **Mention pokemon names on gym strategy:** Enable users to mention their pokemon names on the gym strategy.

### Future Improvements
- [ ] **The whistle:** Allowing 'premium' players to see the referee's analysis of the play, as a way to learn more about the game.
- [ ] **Team Management:** Allow users to create a team to attack and another one to defend their gym.
- [ ] **Improve statistics:** Show more statistics about the battle.
- [ ] **Leveling:** Allow your pokemons to envolve and discover new abilityes over time.
- [ ] **Leaderboard:** Add a leaderboard for a competitive play.
